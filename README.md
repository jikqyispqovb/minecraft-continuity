## Overview

Continuity is a Fabric mod for Minecraft that enables connected texture support using the Optifine CTM (Connected Texture Method) format, allowing resource packs to render glass, bookshelves, stone, and other blocks seamlessly when placed adjacent to matching blocks. It achieves full CTM parity without requiring Optifine, making connected textures accessible in Fabric-based modpacks.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Minecraft Continuity** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Full CTM Support** | Complete Optifine-compatible CTM format connected texture rendering |
| **Seamless Glass** | Adjacent glass panes render without visible borders in builds |
| **Fabric Native** | Built on Fabric API with no Optifine dependency required |
| **Resource Pack Compat** | Works with any resource pack using standard CTM texture definitions |
